# Phone PWA Implementation Plan

Goal: Deliver the agreed Articles of Faith Jumble as an offline-capable phone PWA.
Architecture: React renders HTML tiles; a pure TypeScript engine handles ranges, joins, restored spacing, and endpoint geometry. JSON supplies immutable ordered chunks. Completion alone persists locally.
Tech stack: React, TypeScript, Vite, Vitest, Playwright, Workbox via vite-plugin-pwa.
Spec: Repository README gameplay requirements and the approved conversation design.

- [x] Engine and content: write failing tests for joining groups in either direction, rejecting incorrect neighbors, restoring spacing inside partial words, endpoint thresholds, and validation; implement src/engine.ts and src/articles.json; run npm test.
- [x] Interface: implement src/App.tsx and src/style.css with index, touch mat, permanent joins, replay, return, local completion, and responsive wrapped tiles. Add browser tests covering a real drag, victory, replay, discard, and persistence.
- [x] PWA: add manifest, generated icons, offline precache and update prompt. Build with npm run build; verify offline navigation in a browser.
- [x] Verification: run unit and browser tests plus production build; inspect phone screenshots and document run commands and limitations.

Endpoint contract: leading anchor is left-center, trailing anchor is right-center. Only the trailing anchor of an immediately preceding group can join a leading anchor within 44 CSS pixels. Group IDs are chunk indices; ranges are inclusive. Joined text preserves source word boundaries strictly inside the group's letter range.

Long articles: the mat scrolls vertically, with initial tiles in shuffled, jittered rows. Dragging near the viewport edge scrolls the mat. Assembled tiles wrap to phone width and stay on the mat.

Validation: 7 Vitest cases, 5 production browser cases, and TypeScript/Vite build pass. Code review fixes cover punctuation spacing and phone orientation. Phone index and mat screenshots inspected. Actual-device installation and touch testing remain before release.
